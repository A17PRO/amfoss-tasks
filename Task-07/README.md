# Berry Broker
---

## Functions:
---
-**!bounty**: prints the amount of berries the user has.

![alt text](images/image.png)

-**!setsail**: daily command(resets every 24H), attempts to raid a ship and gives user *500 Berries*.

![alt text](images/image-1.png)

-**!worstgeneration**: prints the table-wise details of all users in a server logged in this bot.

![alt text](images/image-2.png)

-**!duel <rock/paper/scissors>**: starts a minigame where if you win you get 50 berries and if you lose you lose 50 berries.

![alt text](images/image-3.png)

**!logpose**: gives random information of either another user or a random character in one piece.

![alt text](images/image-4.png)
![alt text](images/image-5.png)

**!roast <@user>**: roasts the user u mention. 

![alt text](images/image-6.png)
