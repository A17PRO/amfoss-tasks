# Crypto Tracker

A responsive, real-time cryptocurrency dashboard built with vanilla JS, HTML5 and CSS3.

---

## Features

- Live Market Tracking: Pulls real-time data from CoinGecko using their free tier api key. Tracks 1H, 24H and 7D progress of the cryptocurrency.
- Favorites: Star the crypto you want to track and the app uses the localstorage to save the coin details on your browser.
- Instant Search: Dynamic search grid that uses DOM manipulation so that you don't have to reload the webpage yourself.
- Dark/Light Theme: Custom theme switcher button so you can decide how you want to view your web apps. Syncs with system preferrences and saves the choice locally.

---

## Tech Stack

- **Frontend:** HTML5, CSS3 (Variables, Grid, Flexbox), Vanilla JavaScript (ES6+)
- **API:** [CoinGecko REST API](https://www.coingecko.com/en/api)
- **State Management:** Browser `localStorage` API
- **Icons:** Inline SVGs
